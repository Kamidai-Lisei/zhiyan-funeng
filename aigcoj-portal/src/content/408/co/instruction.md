# 指令系统与 CPU 流水线

## 一、指令格式

- 操作码 + 地址码。定长指令字、变长指令字。
- 零地址、一地址、二地址、三地址指令。
- 扩展操作码：短操作码留给高频指令，长操作码扩展低频指令，注意不能出现前缀冲突。

## 二、寻址方式

| 方式 | 有效地址 | 特点 |
| --- | --- | --- |
| 立即寻址 | 操作数在指令中 | 最快，范围受限 |
| 直接寻址 | EA = A | 简单，寻址范围小 |
| 间接寻址 | EA = (A) | 可多次间接，速度慢 |
| 寄存器寻址 | 操作数在寄存器 | 快，寄存器数量有限 |
| 寄存器间接 | EA = (R) | 常用于指针 |
| 变址寻址 | EA = A + (IX) | 适合数组遍历 |
| 相对寻址 | EA = PC + A | 适合转移指令、位置无关代码 |
| 基址寻址 | EA = (BR) + A | 适合多道程序重定位 |

## 三、CISC 与 RISC

- CISC：指令多、格式复杂、寻址方式多、微程序控制为主。
- RISC：指令少且定长、寻址方式少、寄存器多、流水线友好、硬布线控制。
- RISC 不代表性能一定更高，要看具体实现与编译优化。

## 四、CPU 流水线

经典五段：取指 IF → 译码 ID → 执行 EX → 访存 MEM → 写回 WB。

### 流水线冒险

1. **结构冒险**：资源冲突。解决：指令/数据 Cache 分离、资源重复。
2. **数据冒险**：后一条指令依赖前一条结果。解决：转发/旁路、插入气泡、编译调度。
3. **控制冒险**：分支导致取指错误。解决：分支预测、延迟槽、提前形成条件码。

### 性能计算

- 流水线周期 = 最长一段的时间。
- `k` 段流水线执行 `n` 条指令：`T = (k + n - 1) × Δt`。
- 吞吐率 `TP = n / T`；加速比 `S = 顺序执行时间 / 流水线时间`。
- 理想加速比接近 `k`，受冒险与流水线建立时间限制。

## 五、常考计算

- 主频、CPI、MIPS：`MIPS = 主频 / (CPI × 10^6)`。
- 程序执行时间 `T = 指令条数 × CPI / 主频`。
- Cache 与流水线结合：注意每条指令的访存次数。
- 指令流水线时空图：画表格，标出每段占用的时钟周期。

## 六、易错点

1. 扩展操作码的前缀不能冲突。
2. 相对寻址的基准是 PC，通常指向下一条指令。
3. 流水线加速比不是简单的段数。
4. 数据冒险不一定都要阻塞，能转发就转发。
