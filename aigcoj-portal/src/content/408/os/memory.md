# 内存管理：分页、分段与虚拟存储

## 一、连续分配

- 单一连续分配：简单，内存利用率低。
- 固定分区：分区大小固定，产生内部碎片。
- 动态分区：按需分配，产生外部碎片，需要紧凑。
- 分配算法：首次适应、最佳适应、最坏适应、邻近适应。

## 二、分页

- 逻辑地址 = 页号 + 页内偏移。
- 页表项记录物理块号与状态位。
- 优点：无外部碎片；缺点：有内部碎片，页表占空间。
- 快表 TLB：缓存页表项，命中则跳过访存。
- 多级页表：减少页表常驻内存，但增加访存次数。

### 地址转换

1. 用页号查页表，得到物理块号。
2. 物理地址 = 物理块号 × 页大小 + 页内偏移。
3. TLB 命中：直接拼接；未命中：访存查页表。

## 三、分段

- 逻辑地址 = 段号 + 段内偏移。
- 段表项：段长 + 基址。
- 优点：便于共享、保护、动态增长；缺点：外部碎片。
- 段页式：先分段，段内分页，兼顾两者优点。

## 四、虚拟存储

- 局部性原理：时间局部性、空间局部性。
- 请求分页：页表增加有效位、修改位、访问位。
- 缺页中断：访问页面不在内存，调入后重新执行指令。
- 页面置换算法：
  - OPT：理论最优，无法实现。
  - FIFO：简单，可能出现 Belady 异常。
  - LRU：淘汰最久未使用，性能好，开销大。
  - Clock：循环扫描访问位，近似 LRU。

### 缺页率与有效访问时间

`EAT = (1-p) × 内存访问时间 + p × 缺页处理时间`

缺页率越低，有效访问时间越接近内存访问时间。

## 五、常考计算

- 页表大小 = 页表项数 × 页表项大小。
- 多级页表：地址位数拆分，注意每级页表大小不超过一页。
- 页面置换：画物理块表格，逐次标记命中/缺页。
- 抖动：分配的物理块少于工作集，缺页率急剧上升。

## 六、易错点

1. 页大小是 2 的幂，页内偏移位数 = log2(页大小)。
2. 分页对用户透明，分段对用户可见。
3. 缺页中断属于内部中断，处理后重新执行当前指令。
4. Belady 异常只出现在 FIFO，LRU 不会。
