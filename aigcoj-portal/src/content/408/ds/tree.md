# 树与二叉树：遍历、线索、哈夫曼

## 一、基本性质

- 二叉树第 `i` 层最多有 `2^(i-1)` 个结点。
- 高度为 `h` 的二叉树最多有 `2^h - 1` 个结点。
- 叶子结点数 `n0` 与度为 2 的结点数 `n2` 满足 `n0 = n2 + 1`。
- 完全二叉树按层序编号后，结点 `i` 的左孩子为 `2i`，右孩子为 `2i+1`，父结点为 `⌊i/2⌋`。

## 二、四种遍历

| 遍历 | 顺序 | 典型用途 |
| --- | --- | --- |
| 先序 | 根 → 左 → 右 | 复制树、前缀表达式 |
| 中序 | 左 → 根 → 右 | 二叉排序树有序输出 |
| 后序 | 左 → 右 → 根 | 释放树、后缀表达式 |
| 层序 | 逐层从左到右 | 求宽度、按层统计 |

由「先序 + 中序」或「后序 + 中序」可以唯一确定一棵二叉树；但「先序 + 后序」不能。

## 三、非递归写法要点

- **先序**：根入栈，出栈访问，先右后左入栈。
- **中序**：一路向左压栈，出栈访问，转向右子树。
- **后序**：按「根右左」入栈，最后整体反转，或记录 lastVisited。
- **层序**：队列实现，每轮先记录当前层 size。

## 四、线索二叉树

利用二叉链表中的空指针指向前驱或后继：

- 左指针为空 → 指向中序前驱；右指针为空 → 指向中序后继。
- 增加 `ltag` / `rtag` 区分孩子指针与线索。
- 中序线索树可以不用栈完成遍历，空间 O(1)。

## 五、哈夫曼树与编码

- 每次取权值最小的两棵树合并，直到只剩一棵。
- `n` 个叶子的哈夫曼树共有 `2n-1` 个结点，没有度为 1 的结点。
- 带权路径长度 WPL 最小；编码是前缀码，不会产生歧义。
- 常考：给出权值，画哈夫曼树并计算 WPL 与编码长度。

## 六、易错点

1. 完全二叉树与满二叉树混淆。
2. 已知遍历序列还原树时，没有先找根结点。
3. 哈夫曼编码不唯一，但 WPL 唯一。
4. 树转二叉树：左孩子右兄弟。

> 建议配合题库「二叉树遍历」「哈夫曼编码」类题目练习，把递归与非递归都手写一遍。
